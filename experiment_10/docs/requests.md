完成文本分类机器学习实验，目标：输入文本→特征表示→模型训练→预测标签。使用 sklearn 等机器学习库调用算法，不要求手写算法，但需理解并正确设置模型输入、参数、训练、预测、评价流程。

## 实验流程

必须包含：

数据读取 → 数据预处理 → 文本向量化 → 模型训练 → 验证集调参 → 测试集预测 → 指标评价 → 可视化 → 实验分析。

---

## 特征工程

文本不能直接输入模型，必须转换为固定维度数值向量。

可使用：

* TF-IDF（推荐）
* Bag of Words
* CountVectorizer
* 其他合理方法

要求说明：

1. 为什么需要文本向量化；
2. 为什么需要归一化。

原因：

文本词频差异可能导致高频特征dominant低频特征，因此需要通过TF-IDF、Scaler等方法缩放特征，使不同特征处于相近尺度。

所有文本必须映射到相同维度：

建立词表→词编号→生成固定长度向量→未出现词位置为0。

## 数据划分规则

必须严格划分：

### Training Set

仅用于训练模型参数。

禁止：

* 使用验证集训练；
* 使用测试集训练。

### Validation Set

用于：

1. 选择最佳模型；
2. 调整超参数。

例如：

MLP测试hidden layer=100/200/300，通过验证集选择最佳参数。

### Test Set

仅用于最终评价。

禁止：

* 参与训练；
* 参与调参；
* 使用测试集标签泄露。

最终：

选择验证集最佳模型，在测试集评估。

## 参数与超参数

参数(Parameter)：

模型训练过程中自动学习，例如：

* 权重
* bias

超参数(Hyperparameter)：

训练前人工设置，例如：

* 网络层数
* hidden size
* 学习率
* 正则化参数
* SVM C值

超参数必须通过验证集选择。
